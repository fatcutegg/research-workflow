## 命名ルール

### ファイル名

```
{Prefix}-{番号}{-簡潔な説明}.{拡張子}
```

例:
- `EXP-001-baseline-cnn/`
- `DC-003-attention-plan.md`
- `LN-002-tanaka2025.md`
- `EXP-002-FG-01-loss-curve.png`
- `PS-001-2026-08-progress.pptx`

### 会話中での参照

```
文脈明確な場合:  「FG-01 を見てください」
文脈必要な場合:   「EXP-002 の FG-01 を見てください」
```

## 番号割り当てルール

1. **一貫性**: 同じ Prefix はプロジェクト全体で一意
2. **追記可能**: 新しいリソースは連番で追加
3. **欠番なし**: 削除しても番号を再利用しない
4. **ファイル名にも付与**: 検索性確保
5. **会話中短縮可**: 文脈により Prefix のみで通じる
